# The-forgotten-dungeon
This is a game made in python by GoldenFright. It is a text based game which progresses as the game goes on and gets more complex.
download main.exe (raw) and once run the code would create a .txt file called "data.txt" which stores all game data. WARNING : If this file is deleted all prgress would be lost and alterations would result in issues with the game
Start of the game with /grind
Main objective of the game (to beat the game) is to find and beat the dungeon using weapons
the dungeon is turn based with the player having 3 turns after which the enemies have 2 turns

NOTE : Further changes may apply
